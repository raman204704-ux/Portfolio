# Jatin Minhas - AI Engineer Portfolio

Static portfolio site (HTML, CSS, JavaScript). No build step.

## Structure
- `index.html` - page structure
- `css/style.css` - styling and light/dark themes
- `js/projects.js` - **edit this** to change projects, skills, focus cards and chat answers
- `js/main.js` - rendering, theme toggle, hero animation, chat widget
- `assets/resume.docx` - downloadable resume
- `robots.txt`

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public repo and upload everything in this folder.
2. Settings > Pages > Deploy from branch > `main` / root.
3. Your site: `https://your-username.github.io/<repo-name>/`
